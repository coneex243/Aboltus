**«Аболтус»** — это продвинутый десктопный голосовой ассистент и интерактивный AI-компаньон для Windows с живым трехмерным оверлеем (3D VRM Аватар), локальной языковой моделью (Ollama), поддержкой клонированных голосов и удаленным управлением ПК через Telegram.

---

## ✨ Ключевые возможности

### 🎨 1. Интерактивный 3D Аватар-компаньон
- Полупрозрачный оверлей без рамок прямо поверх ваших окон и игр (на базе `pywebview` + `Three.js` + `@pixiv/three-vrm`).
- Реалистичные 3D-модели формата `.vrm` с динамической сменой скинов (`avatar.vrm`, `avatar2.vrm`).
- Визуальная реакция на статус работы (ожидание команды, распознавание, ответ).

### 🎙️ 2. Голосовое управление и синтез речи
- **Офлайн STT:** Распознавание речи через библиотеку `Vosk` и микрофон компьютера с настраиваемой чувствительностью.
- **Активация голосом (Wake-Word):** Вызов по кодовому слову (по умолчанию: *"том"* или *"джарвис"*).
- **Синтез речи (TTS):**
  - Онлайн нейросетевой голос высокой четкости через `Microsoft Edge TTS` (`ru-RU-SvetlanaNeural`).
  - Офлайн-наборы клонированных голосов с репликами: **Декстер**, **Зеленский**, **Меллстрой**.

### 🧠 3. Локальный AI-мозг (Ollama)
- Подключение к локально развернутой нейросети через API Ollama (`localhost:11434`).
- Переключатель **режима иронии/сарказма** для уникального характера ответов ассистента.

### 📱 4. Удаленное управление через Telegram-бота
- Полноценный контроль над домашним ПК из любой точки мира через защищенного Telegram-бота.
- **Интерактивное меню:** статус батареи и нагрузка системы, мониторинг ресурсов, управление звуком, файлами, погода.
- **YouTube:** поиск видео и загрузка прямо с ПК.
- **Прием голосовых сообщений:** отправьте боту голосовое сообщение в Telegram — ассистент распознает его и выполнит команду на вашем ПК!
- **Безопасность:** авторизация по личному Telegram ID хозяина и паролю.

### ⚡ 5. Автоматизация Windows и Макросы
- **Управление звуком:** громче/тише, выключение/включение звука, установка точного процента (`pycaw` + WinAPI fallback).
- **Управление окнами:** свернуть все, закрыть активное, полноэкранный режим.
- **Быстрый доступ:** открытие системных папок (Загрузки, Документы, Музыка), очистка корзины в один клик.
- **Инструменты:** мгновенные скриншоты, переводчик выделенного текста (`deep-translator`), поиск в Википедии, тест скорости интернета (`speedtest-cli`).
- **Редактор макросов:** привязка собственных голосовых команд к открытию сайтов, программ или скриптов (`macros.json`).

Для удобства в проект добавлены готовые сценарии:

|---|---|
| **`START.bat`** | **Основной запуск ассистента.** Автоматически находит Python/виртуальное окружение и запускает проект. |

## 📦 Установка вручную

### Требования:
- Операционная система: **Windows 10 / 11** (x64)
- Версия Python: **3.10 — 3.12** ([скачать с python.org](https://www.python.org/downloads/))
  *(При установке обязательно отметьте галочку **"Add Python to PATH"**)*
- Установленный браузер Microsoft Edge или компоненты WebView2 (для работы 3D-оверлея).
- *(Опционально)* Установленная [Ollama](https://ollama.ai/) для ответов локальной нейросети.

### 1. Клонирование репозитория
```bash
git clone https://github.com/ВАШ_АККАУНТ/Aboltus.git
cd Aboltus
```

### 2. Создание виртуального окружения и установка библиотек
```bash
python -m venv .venv
.venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Настройка конфигурации
Скопируйте пример файла конфигурации:
```bash
copy config.example.yaml config.yaml
```
Откройте `config.yaml` и настройте параметры под себя (подробнее в [API_KEYS_SETUP.md](API_KEYS_SETUP.md)).

### 4. Запуск
```bash
python aboltus.py
```

## ⚙️ Конфигурация (`config.yaml`)

Основные настройки задаются в файле `config.yaml`:

```yaml
assistant:
  wake_word: "том"              # Фраза для вызова ассистента
  user_name: "сэр"              # Обращение к пользователю
  voice_profile: "dexter"       # Профиль озвучки: default, dexter, zelensky, mell
  ironic_mode: 1                # 1 - саркастичные ответы нейросети, 0 - обычные

stt:
  mic_index: null               # Индекс микрофона (null - микрофон по умолчанию)
  sensitivity: 35               # Порог чувствительности распознавания речи

tts:
  engine: "edge-tts"
  voice: "ru-RU-SvetlanaNeural" # Голос Microsoft Edge TTS
  volume: 80                    # Громкость синтезатора (0-100)

telegram:
  token: "YOUR_TELEGRAM_BOT_TOKEN_HERE" # Токен бота от @BotFather
  password: "YOUR_SECRET_PASSWORD"      # Пароль для доступа
  authorized_user_id: 0                 # Ваш Telegram ID (от @userinfobot)
```

> [!NOTE]
> Подробная инструкция по созданию Telegram-бота и защите ключей находится в файле [API_KEYS_SETUP.md](API_KEYS_SETUP.md).

## 🗣️ Примеры голосовых команд

- **Система и статус:**
  - *"Аболтус, информация"* — отчет о системе, загрузке процессора, памяти и IP.
  - *"Который час"*, *"Какое сегодня число"*.
  - *"Очисти корзину"*, *"Сделай скриншот"*.
- **Звук:**
  - *"Громкость 50"*, *"Громче"*, *"Тише"*, *"Выключи звук"*, *"Включи звук"*.
- **Медиа и интернет:**
  - *"Открой браузер"*, *"Открой ютуб"*.
  - *"Поищи видео [название]"*, *"Скачай текущее видео"*.
  - *"Какая погода"*, *"Курс доллара"*, *"Расскажи шутку"*.
- **3D Аватар:**
  - *"Открой 3D аватар"*, *"Закрой аватар"*.
