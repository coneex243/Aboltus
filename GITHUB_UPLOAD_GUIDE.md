# 🚀 Инструкция: Как загрузить проект "Аболтус" на GitHub

Подробное пошаговое руководство для загрузки проекта в ваш репозиторий GitHub.

---

## 📋 Подготовка перед загрузкой

1. У вас должен быть аккаунт на [GitHub.com](https://github.com).
2. На вашем компьютере должен быть установлен **Git**:
   - Скачать: [git-scm.com/download/win](https://git-scm.com/download/win)
   - При установке выбирайте стандартные параметры.
3. Убедитесь, что в файле `config.yaml` или `.env` **нет ваших секретных ключей**, либо используйте файлы `config.example.yaml` и `.env.example`.

> [!IMPORTANT]
> В проекте уже настроен файл **`.gitignore`**, который автоматически исключает тяжелые файлы весов нейросетей (30+ ГБ), виртуальные окружения и конфиги с вашими личными токенами.

---

## Вариант 1. Загрузка через командную строку / терминал (Рекомендуемый)

Откройте **PowerShell** или **Командную строку** в папке проекта (`D:\Aboltus`) или нажмите правой кнопкой мыши внутри папки и выберите **"Open in Terminal"** / **"Git Bash Here"**.

### Шаг 1. Инициализация репозитория
```bash
git init
```

### Шаг 2. Настройка имени и почты (если делаете впервые)
```bash
git config --global user.name "Ваше_Имя"
git config --global user.email "ваш_email@example.com"
```

### Шаг 3. Проверка файлов
Выполните команду проверки:
```bash
git status
```
Вы увидите список файлов, готовых к добавлению. Обратите внимание, что папки весов моделей (`GPT-SoVITS`, `rvc`, виртуальные окружения) **не** должны там отображаться — их отфильтровал `.gitignore`.

### Шаг 4. Добавление файлов в коммит
```bash
git add .
```

### Шаг 5. Создание первого коммита
```bash
git commit -m "Initial commit: Aboltus Voice Assistant"
```

### Шаг 6. Создание нового репозитория на GitHub
1. Перейдите на [github.com/new](https://github.com/new).
2. Задайте имя репозитория (например: `Aboltus` или `aboltus-voice-assistant`).
3. Выберите приватность: **Public** (публичный) или **Private** (приватный).
4. **ВАЖНО:** Не ставьте галочки "Add a README file", "Add .gitignore" или "Choose a license" (так как все эти файлы уже созданы в проекте!).
5. Нажмите зеленую кнопку **"Create repository"**.

### Шаг 7. Привязка удаленного репозитория и отправка кода
GitHub покажет вам команды под заголовком *"…or push an existing repository from the command line"*. Скопируйте и выполните их (замените `ВАШ_ЛОГИН` на ваш логин GitHub):

```bash
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/Aboltus.git
git push -u origin main
```

При первом push Windows откроет окно для авторизации в GitHub (через браузер или токен). Нажмите **"Sign in with your browser"** и подтвердите доступ.

🎉 **Поздравляем! Ваш проект опубликован на GitHub!**

## Вариант 2. Загрузка через приложение GitHub Desktop (Графический интерфейс)

Если вы не хотите пользоваться командной строкой:

1. Скачайте и установите бесплатную программу [GitHub Desktop](https://desktop.github.com/).
2. Войдите в свой аккаунт GitHub в программе.
3. Нажмите в меню: **File** -> **Add Local Repository...**
4. В поле *Local Path* укажите путь к проекту: `D:\Aboltus`.
5. Программа скажет: *"This directory does not appear to be a Git repository"*. Нажмите на синюю ссылку **"create a repository"**.
6. В открывшемся окне подтвердите имя и нажмите **Create Repository**.
7. В нижнем левом углу введите описание коммита (например: `Initial commit`) и нажмите синюю кнопку **Commit to main**.
8. Нажмите верхнюю кнопку **Publish repository** (можно снять галочку "Keep this code private", если хотите сделать проект публичным).
9. Нажмите **Publish**. Готово!

## ⚠️ Частые вопросы и ошибки

### 1. `remote: error: File ... is 120.00 MB; this exceeds GitHub's file size limit of 100.00 MB`
- **Причина:** Случайно попытались закоммитить большой файл модели или архив.
- **Решение:** Проверьте `.gitignore`. В проекте `.gitignore` уже настроен так, чтобы исключать файлы тяжелее 100МБ.

### 2. `Authentication failed` / `Permission to ... denied`
- **Причина:** Неверный логин/пароль или устаревший токен.
- **Решение:** Используйте вход через браузер (Web Browser Auth) или создайте [Personal Access Token (PAT)](https://github.com/settings/tokens) с правами `repo` и используйте его вместо пароля.
