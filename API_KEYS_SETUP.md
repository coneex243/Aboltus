# 🔑 Настройка API-ключей и Telegram-бота для "Аболтус"

В данном руководстве подробно описано, где находятся ключи, зачем они нужны, куда их указывать и как настроить проект безопасно для залива на GitHub.

---

## 📌 Что было изменено в плане безопасности?

Раньше приватные данные были жестко прописаны в коде `aboltus.py`:
- `TELEGRAM_TOKEN` (токен Telegram-бота)
- `PASSWORD` (пароль для авторизации команд)
- `AUTHORIZED_USER_ID` (личный числовой ID пользователя в Telegram)

### ⚠️ Почему нельзя заливать такие ключи на GitHub?
1. **GitHub Secret Scanning:** GitHub автоматически сканирует каждый коммит. При обнаружении токена Telegram система безопасности блокирует коммит или бот отзывается сервисом.
2. **Угроза безопасности:** Злоумышленники сканируют GitHub с помощью скриптов и могут перехватить бота, отправляя опасные команды вашему компьютеру (запуск программ, удаление файлов, открытие ссылок).

---

## 📂 Где теперь хранятся ключи и настройки?

Все конфиденциальные данные **вынесены из исходного кода** в файл конфигурации:
👉 **`config.yaml`** (или опционально в `.env`).

Сам код `aboltus.py` теперь автоматически подгружает их из `config.yaml` или системных переменных. Если токен не указан или оставлен как шаблон (`YOUR_TELEGRAM_BOT_TOKEN_HERE`), программа **не падает с ошибкой**, а просто отключает модуль Telegram и работает штатно!

---

## 🛠️ Пошаговая инструкция по настройке

### Шаг 1. Откройте `config.yaml`
В корне проекта найдите файл `config.yaml` (или скопируйте `config.example.yaml` в `config.yaml`, если файла нет) и откройте его в любом текстовом редакторе (Блокнот, VS Code):

```yaml
telegram:
  token: "YOUR_TELEGRAM_BOT_TOKEN_HERE"
  password: "YOUR_SECRET_PASSWORD_HERE"
  authorized_user_id: 0
```

---

### Шаг 2. Как получить `token` (Токен Telegram-бота)
1. Откройте Telegram и найдите официального бота **[@BotFather](https://t.me/BotFather)**.
2. Нажмите `/start`, затем отправьте команду:
   ```
   /newbot
   ```
3. Введите видимое имя бота (например: `Aboltus Assistant`).
4. Введите юзернейм бота, оканчивающийся на `bot` (например: `my_aboltus_pc_bot`).
5. BotFather поздравит вас и пришлет длинный токен вида:
   ```
   1234567890:AAH_random_letters_and_numbers_example
   ```
6. Скопируйте этот токен и вставьте в `config.yaml` в поле `token:`:
   ```yaml
   token: "1234567890:AAH_random_letters_and_numbers_example"
   ```

---

### Шаг 3. Как узнать свой `authorized_user_id` (Telegram ID)
Указание вашего ID позволяет боту мгновенно распознавать вас как хозяина без необходимости каждый раз вводить пароль.
1. В Telegram найдите проверенного бота для получения ID, например **[@userinfobot](https://t.me/userinfobot)** или **[@myidbot](https://t.me/myidbot)**.
2. Нажмите `/start`. Бот ответит сообщением с вашим `Id` (например: `750754313`).
3. Скопируйте это число и вставьте в `config.yaml` в поле `authorized_user_id:`:
   ```yaml
   authorized_user_id: 750754313
   ```
*(Если оставить `0`, бот будет требовать пароль при каждом сеансе).*

---

### Шаг 4. Настройка `password` (Пароль доступа)
Придумайте любой надежный пароль и впишите его:
```yaml
password: "ПридумайтеСвойНадежныйПароль2026"
```
Этот пароль запрашивается, если команду пытается отправить пользователь, чей ID не совпадает с `authorized_user_id`.

---

## 🌐 Альтернатива через файл `.env` (для серверов/контейнеров)

Если вы предпочитаете переменные окружения, переименуйте `.env.example` в `.env` и укажите данные там:
```env
TELEGRAM_TOKEN=1234567890:AAH_random_letters_and_numbers_example
TELEGRAM_PASSWORD=ПридумайтеСвойНадежныйПароль2026
AUTHORIZED_USER_ID=750754313
```
